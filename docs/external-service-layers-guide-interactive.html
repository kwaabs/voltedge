Pull a third-party map service — an Esri ArcGIS layer, an OGC WMS/WFS, an XYZ tile set — onto the map as an overlay, fetched through VoltEdge's own server-side proxy so credentials never leave the server. This edition is a working one: pick a type, register a service, toggle it on, click to identify, and watch the SSRF gate decide.

Use As in the top bar. Ada holds metadata:write — she registers services. Priya holds features:read — she toggles and identifies them on the map. Dana has neither. Admin actions lock to what the persona may do.

Who this is for

Administrators who register each service once (Admin → Map settings → the Service layers card), and any map user who then switches those layers on. In the app this is called "Service layers" — there's no "Attach" button; enabled services simply appear as toggles in the Layers panel.

The one idea to carry: a service layer is a live reference you never own. (Contrast Data Import, which copies rows into your own classes. Import to take ownership; a service layer to look at someone else's live data.)

1

What it is

Overlay a third-party map service on your network — raster picture or live vector features.

In plain terms

Someone else publishes a map — the council's cadastre, an imagery provider, your GIS server's FeatureServer. Register it once, and it becomes a layer your users can switch on over the top of VoltEdge's own features.

The browser never talks to the third party. Every tile and query is fetched by VoltEdge's server, which keeps your credentials sealed and vets every outbound address.

Admin → Map settings → Service layers. The catalogue entry, authored once.

Build an entry below. It's gated on metadata:write — switch to Ada to save it.

Try it

Service registration

Entry
The credential is write-only

You type the secret in; VoltEdge seals it with AES-256-GCM server-side and never returns it — the API only ever reports has_credential: true. Edit it later with three states: blank = keep, clear = remove, new value = replace. ⚠️ An authenticated layer needs the server's encryption key configured, and is always proxied (the browser can't hold a server secret).

Discover — for WMS/WMTS/WFS and the Esri types, a Discover button fetches the service's capabilities and auto-fills the layer id(s), version, format, CRS and extent — so you pick from what the service really offers. (XYZ and vector tiles have nothing to discover.)

The proxy & the SSRF gate

Why the browser never calls the third party, and which addresses the server refuses.

In plain terms

Every request goes through VoltEdge's own same-origin proxy (/service-layers/…). That keeps the URL + credential on the server, sidesteps CORS, and lets the server check every outbound address before it connects.

Enter a host the service resolves to, and whether it's public/authenticated — the gate decides.

Try it · SSRF gate

Will the server fetch it?

Try 10.0.0.5, 127.0.0.1, 169.254.169.254 (cloud metadata), 100.64.0.1 (CGNAT) — all blocked — vs a public address.

Under the hood

The address is checked after DNS resolution and on every redirect hop (defeating DNS-rebinding); blocked ranges include loopback, private (RFC 1918/ULA), link-local, CGNAT 100.64/10 and NAT64. Cross-host redirects strip custom headers so an API key can't leak. An authenticated layer is always proxied; only a public, CORS-friendly raster may go direct. Proxy limits: 20 s timeout, 32 MiB per response.

7

The honest edges

Know these before you lean on a layer.

CRS

Vector is reprojected to the map's 3857. A service offering only a non-3857/4326 grid isn't reprojected yet.

WMTS grid

A best-effort Web-Mercator pyramid, not the service's exact matrix set — fine for standard providers.

Vector style

One flat default style; a Mapbox-GL style_url is accepted but not applied yet.

Esri FeatureServer

Read as GeoJSON — needs ArcGIS 10.4+. WFS caps at 5,000 features.

Identify

Needs is_queryable; vector identify only finds features already on screen.

Credentials

Useless without the server encryption key — set it before adding an authed layer.
